# Aurélia Grand — Luxury Hotel Website

A fully responsive, production-grade luxury hotel website built with pure HTML, CSS, and vanilla JavaScript.

## ✦ Features

- **Cinematic hero section** with parallax background & animated scroll indicator
- **Sticky navigation** that transitions on scroll with mobile hamburger menu
- **Rooms & Suites** grid with hover effects
- **Dining section** with overlapping image layout
- **Spa & Wellness** feature cards
- **Experiences** gallery with card hover animations
- **Guest testimonials** slider (responsive)
- **Reservation form** with toast notification
- **Fully responsive** — mobile, tablet, desktop
- **Scroll-triggered reveal animations**

## 🚀 Usage

Just open `index.html` in any browser — no build tools required.

To deploy on GitHub Pages:

1. Push to a GitHub repo
1. Go to Settings → Pages → Source → main branch
1. Your site will be live at `https://yourusername.github.io/repo-name`

## 🎨 Design

- **Fonts**: Cormorant Garamond (display) + Jost (body) via Google Fonts
- **Palette**: Deep blacks, warm golds (`#C9A96E`), off-white
- **Style**: Dark luxury / Art Deco influenced
- **Images**: Unsplash (royalty-free)
